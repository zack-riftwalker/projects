# ابزار Godot

نصب و تست Godot 4.7.2 روی سرور، با دو دستور.

| فایل | کار |
|---|---|
| `setup-godot.sh` | Godot رو توی `~/.cache/clawd-godot/4.7.2/` نصب می‌کنه. اگه نصب باشه، چیزی دانلود نمی‌کنه. آخرین خط خروجی مسیر فایل اجراییه |
| `smoke.sh` | نصب رو چک می‌کنه، پروژه‌ی کوچیک `smoke/` رو یه بار بدون صفحه (headless) و یه بار با `xvfb` اجرا می‌کنه و عکس می‌گیره |
| `smoke/` | پروژه‌ی آزمایشی: یه ماشین حالت سه‌تایی (`idle` → `attack` → `recover`) و یه مستطیل رنگی |

## دستورها

```
GODOT=$(bash tools/godot/setup-godot.sh | tail -1)
bash tools/godot/smoke.sh
```

خروجی سالم: `PASS headless` و `PASS screenshot`. اگه بخوای عکس رو ببینی: `SMOKE_KEEP_PNG=/مسیر/shot.png bash tools/godot/smoke.sh`.

## زمان

- اجرای اول: دانلود ~۷۸ مگابایت (زیپ)، چند دقیقه بسته به اینترنت سرور.
- اجرای بعدی: حدود ۱ تا ۲ ثانیه.

هیچ هوک شروع جلسه‌ای اضافه نشده، چون دانلود ۷۸ مگابایتی برای هر جلسه‌ی بازی فعلی هدره. تو شروع فاز ۱ دوباره تصمیم می‌گیریم.
