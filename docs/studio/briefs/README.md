# دستورهای کار

هر فایل این پوشه یه کار ساخت آماده برای یه سشن تازه‌ست. تهیه‌کننده می‌نویسدشون (اسکیل `producer`).
زکریا یه سشن تازه باز می‌کنه (مدل: Opus 5.5، شاخه‌ی `ph1`) و می‌گه: «دستور کار `docs/studio/briefs/NN-<name>.md` رو انجام بده».

اسم فایل: `NN-<name>.md`، که NN شماره‌ی بعدیِ آزاده. وقتی کار تموم شد، فایل نمی‌مونه اینجا و می‌ره `briefs/done/`.

## قالب

```markdown
# NN · <اسم کار>

**بخش:** <باس / ساخت منطقه / ...>   **اسکیل:** <boss-build / region-build / ...>   **وضعیت:** آماده | در حال انجام (<تاریخ>) | انجام شد (<تاریخ>، <کامیت>)

## پرامپت (همه‌ی این بخش رو به سشن بده)

تو یه سشن سازنده‌ی استودیوی CLAWD هستی. اول `git pull origin ph1`، بعد `CLAUDE.md` و `docs/studio/README.md` رو بخون.
کار: <یه جمله>.
اسکیل: <اسم>، و طبقش کار کن.
سندها: <فهرست آدرس‌ها، هر کدوم با یه خط که چرا>.
کد: <فایل‌ها و تابع‌هایی که احتمالاً دست می‌خورن>.
تمام‌شده یعنی: <تست‌ها و نتیجه‌هایی که باید سبز باشن، اسکرین‌شات‌ها>.
آخر کار:
- کار رو روی `docs/studio/PRODUCER.md` تیک بزن.
- چیزهایی که برای بخش‌های دیگه پیدا کردی رو توی صندوقشون بنویس.
- قدم‌های تست بازی برای زکریا رو، فارسی و کوتاه، توی `docs/studio/PLAYTEST.md` بخش «منتظر تست» بنویس.
- پوش کن به `ph1`. بدون اجازه‌ی زکریا به `main` مرج نکن.

## چرا الان

<یه خط: به کدوم هدف تابلو می‌رسه>
```
