## ۲. خروجی تست Godot (MV0-03)

دو بار پشت سر هم، بار دوم دانلود نداشت:

```
godot 4.7.2 already installed
PASS headless
PASS screenshot (1798 bytes)
real 0m7.1s      ← بار اول بعد از نصب
real 0m1.4s      ← بار دوم
```

عکس رو دیدم: مستطیل نارنجی روی پس‌زمینه‌ی خاکستری. اندازه‌ی زیپ دانلودی: ۷۷٬۸۶۰٬۴۲۴ بایت (از هدر سرور). SHA-256 رو اسکریپت موقع نصب چاپ می‌کنه (نصب اول اینجا بی‌خروجی ثبت شد، پس عدد رو ندارم). سایت چک‌سام رسمی تو تست من پیدا نشد؛ اسکریپت اگه پیدا کنه تأیید می‌کنه، وگرنه فقط هش رو چاپ می‌کنه.

**اشتباه تو اجرا:** اولین بار `pkill -f` شل خودم رو کشت (هشدار `CLAUDE.md`)، و اسم تابع `_set` با متد داخلی Godot برخورد کرد. هر دو درست شدن.
