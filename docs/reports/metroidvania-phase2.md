# گزارش فاز ۲ — Metroidvania (شاخهٔ `ph1`)

## چی ساخته شد
- **MV2-01..06:** ۸ اتاق به‌هم‌وصل (R01..R08) با در، بنچ، نقشه، ذخیره؛ دشمن‌های جدید (Guard، Zombie، Typo…)؛ فوکوس (شفا با متر)، دش بدون i-frame (به‌جز easy)، جدول سختی؛ باس NULL v2 با حمله‌های poke/rain/sweep/dangling/deref؛ جایزهٔ bash و آمار مبارزه.
- **MV2-07 co-op:** کلاینت رله (`autoload/net.gd`)، میزبان با چند اتاق هم‌زمان، مهمان با بدن خودش، اعتبارسنجی ضربه‌ها (۱ ثانیه تاریخچه)، احضار به اتاق باس با هشدار ۳ ثانیه‌ای، زنده‌شدن بعد از ۶ ثانیه، شروع دوباره اگه هر دو بمیرن، اتصال دوباره با توکن.
- **MV2-08:** صفحهٔ عنوان (Continue / New game / Host co-op / Join co-op با کیبورد عددی / Settings)، تنظیمات (سختی، HP باس در co-op ۲۵–۱۰۰٪، صدا، ۳۰fps)، صفحهٔ پایان دمو، موزیک‌های `title boss toolget clear`، صداهای جدید.
- گزینه‌های URL: `host`, `join=<کد>`, `autotest`, `diff=`, و `play` (بدون صفحهٔ عنوان؛ برای تست‌ها).

## تست‌ها (همه PASS)
- `bash tools/godot/test-all.sh`: smoke، ۱۶ تست `--test`، ۷ تیپ parity (حرکت دقیقاً مثل JS)، export، web-check، relay، و `coop-test.sh all`.
- `coop-test.sh all`: co-connect, co-hit, co-rooms, co-summon, co-revive, co-crack, co-resume, co-netfields, co-badline (SIM_LAG=150).
- `node tools/coop-harness.js smoke cache paths mv-serve mv-coop mv-title fight-hits revive soak` → همه PASS (`SOAK_S=20`). `mv-coop` و `mv-title` جدیدن: دو تب مرورگر، یکی روی 127.0.0.1 و یکی روی IP شبکه.
- اسکرین‌شات‌ها: `docs/reports/img-phase2/` (title, settings, join, end).

## تفاوت‌ها با پلن
- فونت پیکسلی علامت `·` و `…` نداره؛ به‌جاش `-` و `...` گذاشتم (خط آمار مبارزه هم همین‌طوره).
- اضافه کردن گزینهٔ URL `play` (پلن نداشت) تا تست‌ها از صفحهٔ عنوان رد بشن.
- تنظیمات تو `user://settings.json` جدا از فایل ذخیره هستن (مهمان فایل ذخیره نداره).
- تغییرهای کوچیک تو تست‌های guard/zombie/dashhurt/platform (موقعیت و زمان)؛ تست zombie ۳.۶ ثانیه صبر می‌کنه.
- هم رویداد `boss` و هم فیلد `fs` در اسنپ‌شات استفاده شدن (دوتایی، برای اصلاح خودکار رویداد گم‌شده).
- `co-resume` یه race داشت (رویداد اول قبل از شنونده می‌رسید)؛ درست شد.

## مراحل تست برای زکریا
۱. `update.bat` رو بزن (فایل `update-branch.txt` با متن `ph1` باید هنوز تو پوشه باشه).
۲. رو PC: `http://localhost:3000/mv/` → `Host co-op`. یه کد ۶ رقمی نشون می‌ده.
۳. رفیقت رو گوشی: همون آدرسی که همیشه برای بازی می‌زنه، با `/mv/` آخرش (مثلاً `http://<IP تو>:3000/mv/`) → `Join co-op` → کد.
۴. با هم تا آخر دمو بازی کنید (در آخر اتاق `README.md`). حداقل ۳ بار با NULL بجنگید، حتی اگه بار اول بردید (با `New game` یا مردن).
۵. بعد از هر مبارزه یه عدد ۵ ثانیه رو صفحه میاد (`NULL 72s - P1 41 hits ...`). ازش اسکرین‌شات بگیر.
۶. این سؤال‌ها رو جواب بدید، از ۱ تا ۵: حس حرکت مثل بازی قبلیه؟ NULL سخت بود یا آسون؟ دشمن‌های جدید منصفانه بودن؟ تله‌پورت به اتاق باس ناگهانی بود؟ لگ داشت؟
۷. اسکرین‌شات‌ها و جواب‌ها رو بفرست.
