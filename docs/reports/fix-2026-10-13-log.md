# رفع مشکلات لاگ ۲۰۲۶-۱۰-۱۳ (لگ گوشی، کند شدن PC، «کرش» موقع رفتن بالا)

لاگ زکریا: T09 → T10 (INFINITE LOOP) → T11 → T16 → N11 → N04، دونفره با گوشی. سه شکایت: موقع رفتن بالا به اتاق بعدی «کرش» می‌کرد؛ گوشی خیلی لگ داشت؛ PC هم کم‌کم بدتر شد، مخصوصاً تو نقشه‌ی NETWORK.

## ابزار اندازه‌گیری (برای دفعه‌ی بعد)
- `--test=perfrooms` (همه‌ی اتاق‌ها، `PERF_ROOMS=N` برای یه منطقه)، `--test=perfgrow` (نشت: تکرار اتاق‌ها)، `--test=perfstay` (یه اتاق طولانی).
- سناریوی `co-perf` (تو `all` نیست): دو ربات تو یه اتاق، هر ۱۵ ثانیه CPU هر فریم و لیست‌های بزرگ هر دو صفحه.

## چیزی که هنوز معلوم نیست
- «کرش» رو از روی لاگ مطمئن نیستم همون برگشتن از شفت باشه (لاگ قبل از 33:36 رو نداشت). اگه بازم شد: اسم اتاق و اینکه صفحه سیاه موند / بازی بسته شد / برگشت پایین.
- `tick-desync piston p0` یه بار تو T11 روی گوشی: تحملش ۰٫۳ ثانیه‌ست؛ با لگ کمتر گوشی باید کمتر بشه.
