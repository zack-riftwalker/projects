## گام ۱ · روح و امضا

**ایده‌ها:**
- **الف) «دو شاخه، یه merge» (انتخاب):** منطقه از هاب دو شاخه می‌شه، هر شاخه ته‌اش یه کلید داره، درِ merge فقط با هر دو باز می‌شه.
- ب) «git log شبِ خودت» به‌عنوان لحظه‌ی اصلی.
- ج) «برگشت در زمان» با revert به‌عنوان محور.

**چرا الف:** تنها ایده‌ایه که کل منطقه رو شکل می‌ده (نه یه اتاق)، دونفره طبیعی جدا و دوباره جمع می‌شید، و همون الگوی fork/join برجه که توی بازی کار کرده؛ git log (ب) سر جاش توی G02 می‌مونه (S6، تأیید شده)، فقط «لحظه‌ی اصلی» نیست.

**جزئیات:**
- **فعل اصلی:** checkout (اهرمی که بین نسخه‌ها عوض می‌کنه و بلوک‌های سبز `+` و قرمز `−` رو جابه‌جا می‌کنه)، و آخر منطقه revert.
- **سیستم امضا: شاخه و merge.**
  - G03 (هاب) دو راه داره: غرب `feature/a` (G04 → G09)، جنوب `feature/b` (G06 → G07 → G10).
  - ته هر شاخه یه **کلید شاخه** هست (`branch:a` در G09، `branch:b` در G07). کلیدها مشترکن (D6).
  - G08 `merge` دو در داره، یکی از هر شاخه؛ درِ پایینش (به بیرون از merge، G11) فقط با هر دو کلید باز می‌شه (قفل «۲ از ۲»، همون نوع قفل fork/join برج).
  - **تنها:** یه شاخه، بعد اون یکی (از G08 می‌شه برگشت به هاب). **دونفره:** هر کدوم یه شاخه، و توی G08 از دو در به هم می‌رسید. هیچ همزمانی لازم نیست.
  - وقتی کلید دوم برداشته می‌شه: یه کامیت تازه روی دیوار G08 نوشته می‌شه `Merge branch 'feature/b'` و روی نقشه دو خط شاخه به هم وصل می‌شن (خودِ نقشه‌ی منطقه یه git graph ـه، 08).
- **توانایی تازه:** revert (جایزه‌ی REGRESSION در G12). آموزشش G13 `reflog`، امتحانش G14 `revert.sh` (پل فروریز + کلید فشاری).
- **حال و هوا:** ساعت 05:33. آرشیو سپیا: کامیت‌ها مثل سنگ‌نوشته، تگ‌ها مثل پرچم (`v0.1`، `v1.0`). موسیقی موتیف‌های w1، آهسته‌تر و گاهی برعکس (08).
- **جای منطقه توی قصه (STORY §۵):** هر منطقه یکی از خرابی‌های refactor امشبه. GIT HISTORY جاییه که خرابی **ثبت شده**: هر نسخه‌ی کد هنوز این پایین هست، از جمله نسخه‌ای که کار می‌کرد. Clawd خطا رو توی تاریخچه دنبال می‌کنه (bisect = پیدا کردن کامیتی که خراب کرد). REGRESSION («چیزی که درست بود و دوباره خراب شد») باس همین‌جاست. داستان خود باس مال boss-design ـه.
- **لحظه‌ی یادموندنی:** `Merge branch 'feature/b'`: دو نفر از دو در وارد G08 می‌شن، دو کلید روی دو پایه، درِ پایین با صدای بلند باز می‌شه و خط‌های نقشه به هم می‌رسن.

## گام ۲ · مسیر

**ایده‌ها:**
- **الف) دو شاخه‌ی موازی از هاب، ترتیب آزاد (انتخاب).**
- ب) پشت سر هم: کلید شاخه‌ی a درِ شاخه‌ی b رو باز کنه.
- ج) هر شاخه فقط برای یه بازیکن (دونفره اجباری).

**چرا الف:** طراحی 08 همینه و نقشه‌ش چک شده؛ تنها و دونفره هر دو بی‌گیر کار می‌کنه (ب جدا شدن دونفره رو می‌کشه، ج قانون «هر مانع رو یه نفر تنها هم حل می‌کنه» رو می‌شکنه).

**ریتم مسیر اصلی:** G01 ورود و نیمکت → G02 پلکان git log (lore، `tree`) → G03 هاب و ترمینال (انتخاب شاخه) → [شاخه a: G04 اهرم checkout → G09 چاه checkout → کلید A] و [شاخه b: G06 دشمن‌های قدیمی → G07 bisect → کلید B → G10 راهرو] → G08 merge → G11 نیمکت و آینه → G12 REGRESSION → G13 آموزش revert → G14 پازل آخر → P07 آسانسور به PRODUCTION.

**ورودی‌ها (با چی می‌رسی):**
- **N17 → G01** (اصلی): bash، catch، ssh حتماً؛ به‌علاوه‌ی sudo یا agents (هر کدوم که راه NETWORK رو باز کرده)؛ curl فقط اگه CRAWLER رو زده باشی. **پس مسیر اصلی GIT فقط با bash، catch و ssh حل می‌شه.** sudo و curl فقط برای رازها و میان‌برها.
- **R06 → G16** (symlink): فقط بعد از اینکه یه بار از طرف GIT بازش کردی (W1).
- **X12 → G04** (vendor/، ssh): از DEPENDENCY HELL (وقتی ساخته شد).
- **P07 → G14** (آسانسور rollback): از PRODUCTION (وقتی ساخته شد).

**برگشت و حلقه‌ها:**
- **N17 دوطرفه‌ست:** از G01 باید بشه N17 رو بالا رفت (با پرش از دیوار). گام ۳ با شبیه‌ساز چکش می‌کنه (`WORLD.md` ۶.۲ شماره‌ی ۳).
- **G09 و G07 دوطرفه‌ان:** G09 با اهرم checkout از پایین هم بالا می‌ره؛ توی G07 هر جواب غلط تو رو به یه چاه کناری می‌ندازه که با پرش دیواری به طبقه‌ی قبل برمی‌گرده، و همین چاه‌ها راه بالا رفتن از ته G07 هم هستن.
- **میان‌بر از طرف عمیق (اصل ۳ از 08):** سقف G13 `reflog` یه دریچه به G10 داره که فقط از پایین باز می‌شه (اهرم `git reflog` بعد از REGRESSION). از G10 تا هاب: G10 → G08 → G09 → G04 → G03. نیمکت G11 کنارشه.
- **یک‌طرفه‌ها (W5):** دریچه‌ی G13 → G10 (از پایین؛ بعدش دوطرفه)؛ کف --force G14 → G15 (سکو زیر دهانه، برگشت به G14، از 08). هیچ سقوطی شریک رو گیر نمی‌ندازه.
- **ته منطقه، تا PRODUCTION ساخته بشه:** درِ شرقی G14 درِ «ادامه دارد» (`to be continued in /var/prod`) ـه، مثل T11.

**جاهایی که ممکنه گم بشی و سرنخش:**
- **«کدوم شاخه رو رفتم؟»** هاب G03 یه git graph روی دیوار داره: شاخه‌ای که کلیدش برداشته شده سبز می‌شه. G08 هم دو پایه‌ی کلید داره که خالی و پرشون پیداست.
- **bisect (G07):** هر دوراهی دو تابلو داره (`good` و `bad`، مثل خروجی `git bisect`)؛ تابلوی درست از روی پیامی که روی دیوار بالاش نوشته پیدا می‌شه (`tests: pass` / `tests: fail`). جواب غلط فقط برت می‌گردونه، هیچ‌وقت آسیب نمی‌زنه.
- **revert رو کجا لازم داری؟** «؟» روی نقشه (D50) برای کلیدهای فشاری R17 و پل‌های G14، و خط changelog بعد از گرفتنش: `changelog: something in /src now answers to revert`.
