# 07 · مقایسه‌ی co-op نسخه‌ی JS با نسخه‌ی Godot، و قانون‌هایی که جلوی باگ رو می‌گیرن

**نتیجه:** نسخه‌ی JS «بی‌باگ» به دنیا نیومد؛ سه فاز بازی واقعی و حدود ۶۰ تست دونفره (با خط بد شبیه‌سازی‌شده) پشتش بود. درس‌هاش حتی تو [`04-coop-design.md`](04-coop-design.md) §۳ نوشته شده بود، ولی پیاده‌سازی فاز ۲ خیلی‌هاش رو نیاورد و هیچ تستی هم نبود که نبودنشون رو بگیره. این سند هر ویژگی co-op نسخه‌ی JS (`public/index.html`، ماژول `js/coop.js`) رو کنار Godot (`godot/src`) می‌ذاره، می‌گه چی اومد و چی نه، و قانون‌ها و ابزارهایی که از این به بعد جلوی همین نوع باگ‌ها رو می‌گیرن.

تاریخ: ۲۰۲۶-۱۰-۱۰. نقطه‌ی شروع مقایسه: `ba3aa85` (آخر فاز ۲). همه‌ی تغییرها روی برنچ `ph1`.

## ۳. قانون‌ها برای هر تغییر بعدی

۱. **وضعیت، نه رویداد.** هر چیزی که باید «همین الان» درست باشه (موسیقی، قفل کنترل، وضعیت مبارزه، مرگ) یا هر فریم از وضعیت ساخته می‌شه یا تو snapshot میاد. رویداد فقط برای کارهای یک‌باره (افکت، صدا). نمونه: `Main.song_for`.
۲. **آسیب P2 رو گوشی تشخیص می‌ده.** هر آسیب سمت میزبان به P2 یا `room.harm_zone` می‌شه یا از `RemotePlayer.hurt` خودش zone می‌سازه. هیچ‌وقت `q.hurt` روی بدن شریک حساب نکن.
۳. **هر چیزی که جنگ مهمان از دشمن می‌خونه باید تو رکورد باشه.** دشمن یا باس جدید → `NetClasses.record/apply` و `net_fields`، بعد تست `parity`. اگه فیلدی جا افتاده باشه، `parity` رد می‌شه.
۴. **«الان» شریک رو باور نکن.** چک ضربه، برداشتن آیتم و نشونه‌گیری از گزارش‌های اخیر P2 و تاریخچه استفاده کنن، با حدی که با پینگ بزرگ می‌شه.
۵. **هر رد شدنی دیده بشه و قابل تکرار باشه.** حکم ضربه‌ی رد شده تو لاگ؛ درخواست آیتم بعد از ۰٫۶ ثانیه دوباره.
۶. **اتاق فقط تا وقتی کسی توشه.** بدن شریک دقیقاً تو یه اتاق. ناظر این‌ها رو چک می‌کنه.
۷. **هر درس یه تست داره، و تست باید رو کد قدیمی رد بشه** (قانون `CLAUDE.md`).
۸. **ناظر همیشه روشن.** هر خط `INVARIANT` یا `SCRIPT ERROR` یه سناریو رو رد می‌کنه (`coop-test.sh`). باگ جدید از یه نوع جدید → یه قانون جدید تو `watchdog.gd`.
۹. **رو خط بد تست کن.** `co-badline` و `co-soak` بخشی از `test-all` هستن.
۱۰. **بیلد هر دو صفحه یکی باشه.** هشدار «DIFFERENT BUILDS» و خط سوم پنل دیباگ.

## ۵. تغییر قانون طراحی (تأیید Zakaria، ۲۰۲۶-۱۰-۱۰)

قانون ۴ از `04-coop-design.md` («احیا وقتی دور هستید») عوض شد: **شمارش ۶ ثانیه‌ای احیا فقط تو مبارزه‌ی باس هست.** بیرون از مبارزه، مرگ هر بازیکن مستقیم به نیمکت خودش (یا شروع) با جون کامل برش می‌گردونه، مثل بازی تک‌نفره. P2 با رسیدن به نیمکت، اون رو مال خودش می‌کنه. «Restart room» میزبان P2 رو هم برمی‌گردونه.

## ۶. هنوز باز (به ترتیب ارزش)

1. نرخ ارسال تطبیقی سه‌سطحی و تشخیص قطعی (stall) مثل JS.
2. pause به‌صورت وضعیت (مثل `hs` نسخه‌ی JS) به‌جای رویداد: مهمانی که وسط pause دوباره وصل بشه الان نمی‌فهمه بازی ایستاده.
3. snapshot دلتا، اگه اندازه‌گیری روی خط واقعی نشون داد پهنای باند مشکله.
4. پنل 2P کامل (نرخ ارسال، KB/s، تعداد قطعی‌ها) برای عیب‌یابی خط.
