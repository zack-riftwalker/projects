# ریاضی‌لند — بازطراحی مسیر (سبک دوولینگو)

یک بازی ریاضی آفلاین برای پایه‌های هفتم تا نهم، فارسی و راست‌به‌چپ، در **یک فایل HTML** (`index.html`) که بدون سرور و بدون اینترنت کار می‌کند. معلم‌ها همین فایل را پخش می‌کنند.

پیشرفت کاربران قدیمی حفظ می‌شود (کلیدهای `mh_users`، `mathHero.shop.v1` و … دست‌نخورده؛ سکهٔ فروشگاه قدیمی یک‌بار به حساب اصلی منتقل می‌شود). جزئیات هر فاز و «تصمیم‌های باز» برای بازبینی: `CHANGELOG.md`. گزارش فنی فاز ۰: `docs/phase0-report.md`.

## اجرا
- فقط `index.html` را در مرورگر (ترجیحاً Chrome) باز کنید. برای نصب مثل اپ (PWA) فایل‌ها را روی یک سایت (مثلاً GitHub Pages) بگذارید: `index.html`، `manifest.webmanifest`، `sw.js`، `icon-192.png`، `icon-512.png` کنار هم. از `file://` نصب PWA کار نمی‌کند ولی بازی عادی کار می‌کند.
- با هر انتشار تازه، مقدار `CACHE` در `sw.js` را عوض کنید تا کش قدیمی پاک شود.

## تست
Playwright و Chromium از قبل نصب‌اند (چیزی نصب نکنید).
```
node riazi-land/tests/smoke.js            # تست دودی (آخرین خط: SUMMARY: X passed, Y failed)
node riazi-land/tests/smoke.js PHASE5     # فقط تست‌هایی که نامشان این متن را دارد
node riazi-land/tests/routes.js           # مسیر مرده + پیمایش همهٔ دکمه‌ها
node riazi-land/tests/shots.js phase-N    # اسکرین‌شات صفحه‌های برچسب‌خوردهٔ فاز N (--all برای همه)
node riazi-land/tests/final-shots.js      # اسکرین‌شات نهایی (۳۹۰×۸۴۴ و ۱۲۸۰×۸۰۰، دو برابر) در docs/shots/final/
```
تست‌های بعدی را با `T('نام', async ({browser}) => {...})` به انتهای `tests/smoke.js` اضافه کنید؛ `tests/fixtures/legacy-user.json` یک کاربر قدیمی واقعی برای تست مهاجرت است.

## محدودیت‌ها
- **Push / یادآوری از سرور نداریم** (فایل ایستا است؛ فقط پیام‌های داخل اپ).
- **لیگ نیازمند Firebase معلم است:** بدون آدرس پایگاه داده و کد کلاس (⚙️ تنظیم لیگ) فقط جدول همان دستگاه نشان داده می‌شود. هیچ رقیب ساختگی وجود ندارد.
- **بانک سؤال را مدل ساخته است** و ممکن است اشکال داشته باشد؛ معلم ریاضی لطفاً `docs/phase3-content.md` و نمونه‌های درس را با کتاب تطبیق دهد (اصطلاح‌ها مثل متمم/مکمل، π=۳ در حجم‌ها).
- داده‌ها فقط روی همان مرورگر ذخیره می‌شوند؛ برای انتقال از «پشتیبانی ← پشتیبان‌گیری» استفاده کنید.
- چند منبع سکهٔ قدیمی نتیجه‌محور (پایان بازی‌های باشگاه، مأموریت‌های ویژهٔ ماجراجویی، مسابقهٔ زنده) هنوز سکه می‌دهند (تصمیم باز).
